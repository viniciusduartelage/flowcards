# Support (FlowCards)

Need help with FlowCards (Power BI custom visual)?

## How to get support

- Report a bug or request a feature by opening an issue at
  https://github.com/viniciusduartelage/flowcards/issues
- Email: viniciusduartelage@outlook.com

Support is provided on a best effort basis. When you report a problem, please
include your Power BI version, what you expected, what happened, and a
screenshot if possible.
